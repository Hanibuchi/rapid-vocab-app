# 英単語学習アプリ

4択クイズ形式で英単語を覚えられる、ブラウザだけで動く単語学習アプリです。
インストール不要・サーバー不要で、`index.html` というファイル1つだけで完結しています。

AWL（Academic Word List）レベル1〜10、合計570語の単語セットが最初から入っているので、
何もアップロードしなくてもすぐに始められます。さらに、自分の単語帳を追加することもできます。追加した単語の発音は自動生成されます。

---

## 使い方（2通りあります）

どちらの方法で使っても、アプリの機能や操作方法は完全に同じです。
「今すぐ試したいだけ」ならA、「自分のパソコンに保存して使いたい」「オフラインでも使いたい」ならBがおすすめです。

### A. GitHub Pages で使う（一番かんたん）

インストール不要で、リンクを開くだけで使えます。

1. 以下のURLをブラウザで開く

   ```
   https://hanibuchi.github.io/rapid-vocab-app/
   ```

2. これだけで学習を始められます。

### B. GitHub からダウンロードして使う

自分のパソコンに保存して、オフラインでも使いたい場合はこちらの方法を使います。

1. このリポジトリのページ右上あたりにある緑色の **`Code`** ボタンをクリックする
2. **`Download ZIP`** をクリックしてZIPファイルをダウンロードする
3. ダウンロードしたZIPファイルを好きな場所に解凍する
4. 展開してできたフォルダの中にある **`index.html`** をダブルクリックして開く

   - ブラウザが自動的に起動して、アプリが表示されます。
   - おすすめのブラウザは **Google Chrome** です（後述の発音機能がきれいに聞こえます）。

> `index.html` さえ手元にあれば動くので、フォルダごとUSBメモリやクラウドストレージに入れて
> 別のパソコンに持っていっても使えます（ただし後述の通り、学習の記録はパソコン・ブラウザごとに別々に保存されます）。

## 共通の使い方（AでもBでも同じです）

### 1. 単語セットを選ぶ

最初の画面（設定画面）の「単語セット」欄に、単語ファイルの一覧が表示されます。

- 最初から `AWLレベル1`〜`AWLレベル10` が登録されています。
- 各ファイルの右側にあるスイッチで、そのファイルを出題対象にするかどうかを切り替えられます。
- 一覧の上にある「すべて選択 / 解除」スイッチで、全ファイルをまとめてON/OFFできます。
- 一覧の下にある「ファイルを選択」ボタンから、自分の単語ファイル（`.txt` または `.csv`）を追加できます。
  - ファイルの中身は「英単語,日本語訳」を1行ずつ書いたものです（詳しくは画面右上の「単語セット追加方法」からも確認できます）。
- 不要になったファイルは、一覧の右側にある「✕」ボタンで削除できます。

### 2. モードと設定を選ぶ

- **モード**:
  - 「英語 → 日本語」: 英単語（と発音）を見て・聞いて、正しい日本語訳を選びます。
  - 「日本語 → 英語」: 日本語訳を見て、正しい英単語を選びます。
- **設定**:
  - 時間制限で自動的に次へ進む: ONにすると、制限時間内に答えられなかった問題は自動的に不正解扱いになり次の問題へ進みます。OFFの場合は、時間切れ後でも正解を選べば正解として扱われます。
  - チェックのついた単語だけ出題する: ONにすると、後述の「チェック」を付けた単語だけが出題されます。
  - 綴りを表示する（英語→日本語モードのみ）: OFFにすると英単語の綴りが隠れ、発音だけを頼りに答える練習になります。

出題対象の単語が0問のときは「開始する」ボタンが押せなくなっています。

### 3. クイズに答える

- 4つの選択肢の中から答えを選びます。
- わからないときは、選択肢の下にある「わからない」ボタンを押すと、不正解として扱われ、正解が表示されて次に進みます。
- 間違えた単語には自動で「チェック」が付きます。
- 選択肢の下にある「チェックをつける」スイッチで、自分の判断で手動でもチェックを付けたり外したりできます。
- 途中でやめたくなったら「設定へ戻る」ボタンでいつでも中断できます（それまでの結果はきちんと保存されます）。

### 4. 結果を確認する

全問答え終わると、結果画面に表として一覧が表示されます。

- 表の中でチェックの付け外しをその場で行えます。
- 「同じ設定でリトライ」: 同じ単語セット・設定でもう一度挑戦します。
- 「間違えた問題だけリトライ」: 今回間違えた単語だけをもう一度出題します。
- 「設定画面に戻る」: 最初の設定画面に戻ります。

### データの保存について

- チェックの状態や設定内容は、ブラウザの中（IndexedDB）に自動で保存されます。次に開いたときも続きから使えます。
- この保存データは、**開いたブラウザ・パソコンごと**に別々に保存されます。GitHub Pages版とダウンロード版、あるいは異なるパソコンの間でデータが自動的に共有されることはありません。
- インターネットに送信されるデータはありません（発音機能がブラウザ標準の音声合成を使う都合上、ブラウザ・OSによっては発音時のみ通信が発生する場合があります）。

## 動作環境

- モダンなブラウザ（**Google Chrome推奨**、Edge / Safari / Firefox でも動作します）
- インターネット接続は、GitHub Pages版を開くとき以外は不要です。

## AWL（Academic Word List）について

最初から入っている単語セット「AWLレベル1〜10」は、**Academic Word List（学術英単語リスト）** という、
大学の教科書や論文など、分野を問わず学術的な英語でよく使われる単語をまとめたリストです。

- ニュージーランドの言語学者 Averil Coxhead氏が、様々な学術分野の文章を分析して作成したもので、
  英語圏の大学進学準備や、TOEFL・IELTSなどのアカデミックな英語試験の対策によく使われています。
- 全部で570の単語ファミリー（同じ語源から派生した単語のグループ）が、使用頻度の高い順に
  10個のサブリストに分けられており、このアプリの「レベル1」〜「レベル10」はそれぞれこのサブリスト1〜10に対応しています。
  レベル1が最も頻出で重要な単語、レベル10にいくほど頻度は下がります。
- 日常会話というよりは、レポートや論文、ニュースなどの硬めの文章でよく出てくる単語が中心なので、
  中〜上級者の語彙力強化や、アカデミックな英語を読む機会がある人におすすめです。
